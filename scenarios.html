    交通服务与能力改进的参考设计

    场景包库

    每个场景包围绕一项具体业务，汇集任务目标、参与系统、协作过程、责任分工及技术要求，为相关系统的设计与集成提供参考。

    覆盖城市道路、水运、低空、高速公路等多种交通方式，场景范围可继续扩展。当前内容为审阅资料，实际应用条件及验证要求在各场景中单独列明。

    SP-01 · 高速公路

    高速公路自主式监测预警调度

    高速公路事件自主处理

    业务边界：以H-017货车疑似事故为例，主动查找、核实、预警、清障协调及恢复核验。

    自主协同：智能体连续组织摄像机搜索和补查，结合大模型研判与Skill调用，根据队尾和资源变化调整安排。

    参考设计草案

    完成核验：分别核实清障、通行、排队、措施解除及资源交接；未确认事项继续跟踪。

    SP-02 · 城市道路

    城市道路应急通道

    任务运行

    业务边界：服务于已认证应急任务的道路区段和时间窗口，协调通行保障与周边交通。

    自主协同：持续识别车辆到达与道路变化，滚动安排跨路口措施；两种配置分别核验人工执行与车路事务执行条件。

    参考设计草案

    完成核验：实际通过任务区段，措施解除、资源释放和恢复结果确认；终止任务另记退出结果。

    SP-03 · 道路与低空

    低空无人机道路事件侦察与地面协同处置

    任务运行

    业务边界：在核定道路事件范围内开展低空侦察，衔接地面处置与道路恢复；飞行与地面职责分别落实。

    自主协同：依据侦察证据、飞行条件及处置反馈调整观察、地面任务和交通措施；登记装备按各自权限执行。

    参考设计草案

    完成核验：地面结果确认、航空器安全结束、交通及作业措施解除、资源与数据责任交接分别核验。

    SP-04 · 城市道路

    城市道路能力演进

    能力演进

    业务边界：管理城市道路能力版本从问题诊断到稳定基线的更新过程，现场交通任务继续按有效基线运行。

    自主协同：协调候选构建、独立验证、发布和观察反馈；逐项审定与预授权自动准入分别配置。

    参考设计草案

    完成核验：批准接纳范围内实际版本及观察结果达标，形成稳定基线；发布指令或局部成功不足以完成。

    SP-05 · 高速公路

    高速公路智慧扩容

    任务运行

    业务边界：围绕既有主线、互通、收费站及相邻影响区协调运行措施，提高有效通行能力；不预设扩容比例。

    自主协同：随需求、瓶颈及设施状态变化联动获准措施，依据实际执行和交通影响持续修正；车辆控制另核准入。

    参考设计草案

    完成核验：本轮运行目标经评价确认，临时措施解除或转入批准配置，车辆协同退出及资源交接核验完成。

    SP-06 · 水运

    限定航段内多船会遇协同避让

    任务运行

    业务边界：服务于核定航段内一次多船会遇，相关成员随态势复核；各船保留自身操纵与安全责任。

    自主协同：各船识别协同需要、协调相容安排并独立执行，依据成员和实际运动变化持续调整。

    参考设计草案

    完成核验：实际观测支持安全通过，风险满足退出判据，各船完成控制交接；协商同意不足以完成。

    SP-07 · 城市道路

    大型赛事散场接驳与道路交通协同保障

    任务运行

    业务边界：把离场观众送达轨道站点和外围接驳点，同时保障周边道路通行。

    自主协同：公交调度、客流组织和道路信号联合调整，核对上客、放行及接收条件，按实际执行持续修正。

    参考设计草案

    完成核验：剩余需求核清并完成疏运，实际运抵及接收确认，积压已处置并核验道路恢复；发车不等于送达。

    SP-08 · 公路作业

    公路养护作业交通协同保障

    任务运行

    业务边界：协调计划性占道养护的交通保障、作业防护与设施布撤，覆盖前置部署至通行恢复。

    自主协同：依据交通、防护、进度与装备变化，在核定方案内联动作业安排和交通措施，各方执行并反馈。

    参考设计草案

    完成核验：作业结束、人员装备撤离、设施撤除或批准保留分别核验，道路责任方确认恢复；施工完成不等于可撤防。

    SP-09 · 空地运输

    公共无人机接驳站多运营商协同接运

    任务运行

    业务边界：不同运营商共享公共站点，衔接无人机到达、货物交接与地面接运；本站接驳与全程运输分别管理。

    自主协同：依据到达、资源占用与接运能力共同修订安排，各运营商确认并执行本方任务，按实际交接持续调整。

    参考设计草案

    完成核验：逐运输单元确认接收、责任交接及后续发运，核验装备状态和资源释放；本站完成不等于全程送达。

    2. 能力与责任配置

    本地环境、第三方依赖与安装
    类别内容与安装要求
    已包含的本地文件Skill、公共架构模型、JSON Schema、校验器、页面生成器、CSS/JS、参考规格及页面。保留解压后的 site/ 目录结构。
    运行环境Python 3.12（已测 3.12.14）、pip、venv 和浏览器。ZIP 不包含解释器或第三方二进制库。
    直接第三方依赖jsonschema 4.23.0：规格校验；lxml 6.1.1：HTML/SVG 处理。
    间接第三方依赖attrs 26.1.0、jsonschema-specifications 2025.9.1、referencing 0.37.0、rpds-py 2026.6.3、typing-extensions 4.16.0。
    模型与可选工具自然语言辅助编制需要 Skill 工具及可用模型账户；Python 校验、生成、回传不调用模型 API。Git 和 Node.js 不属于基本运行依赖。

    解压后按包内说明创建虚拟环境，执行 python -m pip install -r requirements-scenario.txt。首次安装需要可用软件源；离线机器需另行准备匹配平台的依赖文件。

    python tools/export_scenario_submission.py --spec data/scenarios/spNN.json --materials submission-notes
